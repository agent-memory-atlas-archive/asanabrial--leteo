# The hard set

Questions the lexical search cannot answer by matching words, so that the semantic
stage has something to do. **They are generated by an LLM (Claude) and their
translations have not been read by a native speaker** — the Basque and Galician ones
least of all. Quote any number from them with that sentence.

| file | what | n |
| --- | --- | --- |
| `data/para_en.json.gz` | English paraphrases of a memory's subject that share no content word with it | 120 |
| `data/xl_<lang>.json.gz` | the same paraphrases written as questions in each of the other twelve languages (`ca de es eu fr gl it nl pl pt ro sv`), keyed to the English memory | 12 × 80 |
| `data/mem_<lang>.json.gz` | the 40 engram-bench targets translated into `de es eu gl`; the engram-bench queries and the paraphrases are asked against them | 4 × 40 memories |
| `data/absent.json.gz` | questions nothing in either project is about; silence is the right answer | 80 |

`mem_<lang>` queries are the 117 engram-bench ones plus the 120 paraphrases, asked of a
store whose 40 target memories are replaced by their translation. That makes the hard
set 120 + 960 + 948 = 2,028 questions; the controls (the engram-bench queries asked
in the project where their target does not exist, and `absent.json` in both projects) are
reported beside it and not counted in it.

The files are deterministic gzip (`tools/semantic/pack_gz.py`), because 237 KB of generated
JSON is neither reviewable nor small as text; `checksums.json` records the hash of each file
as stored and of the JSON it decompresses to, and `check_sets.py` verifies both before it
checks anything else. Read one with `gzip -dc tools/semantic/hardset/data/para_en.json.gz`.

`check_sets.py` checks the claim the set rests on: that no English paraphrase shares a
content word with its English target (two words are shared when equal after folding
accents, or when both are five characters or more and begin with the same five). It
exits non-zero on a violation. It also counts, and does not fail on, the paraphrases that
share a word with the *translated* memory through a cognate (`permission`/`permiso`) or
a term the translation kept (`FOIT`): 8 of 480.

`evaluate.py` is the measurement. It needs the model, which is a file the binary loads:
set `LETEO_MODEL_DIR=assets/model`, or the stage is off and both passes are the same. See the module docstring for what it compares and
what it exits on.
